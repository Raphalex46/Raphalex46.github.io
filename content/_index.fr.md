## À propos de moi

Je suis actuellement en train de faire un doctorat en informatique dans [l'équipe ICPS du laboratoire ICube](https://icps.icube.unistra.fr/).

Je travaille sur les optimizations de compilateurs et les transformations de
code dynamiques spéculatives, plus précisément sur le sujet du
**multi-versioning**. C'est à dire, le fait de sélectionner la version la plus
performante d'un programme donné dans un contexte d'exécution donné.

J'aime les ordinateurs, la musique (particulièrement le métal), le karaoké et plein d'autres trucs !

### Jeux

J'ai participé à quelques _game jams_. Vous pouvez jouer aux jeux sur ma page [itch.io](https://raphalex.itch.io/).

- [The Bloody Raise](https://nawreua.itch.io/the-bloody-raise) est un jeu fait
  à l'occasion de la [SCREAM JAM 2025](https://itch.io/jam/scream-jam-2025). Le
  jeu est conçu pour que vous y jouiez plusieurs fois de suite pour découvrir
  toute l'histoire.
- [The Funny Place](https://canopteks.itch.io/the-funny-place) est un jeu fait
  à l'occasion de la Global Game Jam 2024. C'est une sorte de _god game_ où
  vous devez rendre les gens heureux (ou tristes) en utilisant les outils à
  votre disposition. C'était à l'origine pensé comme un jeu de puzzles où vous
  auriez dû équilibrer l'utilisation de vos outils pour rendre les gens heureux
  ou tristes dans le but d'augmenter le bonheur général du mieux que vous
  pouvez. Nous n'avons pas eu le temps de tout finir, donc le jeu est plutôt
  une sorte de démo technique, mais les éléments essentiels sont là.
