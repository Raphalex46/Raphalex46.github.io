About me

I am currently doing a PhD in computer science in the ICPS team of the ICube laboratory.

I work on compiler optimizations and speculative runtime code transformations, more specifically on the subject of multi-versioning. That means, selecting the best performing version of a given program in a given execution context.

I like computers, music (especially of the metal variety), singing karaoke and beer.

Games

I participated in a few game jams. The games can be found on my itch.io page.

  • The Bloody Raise is a game made for SCREAM JAM 2025. It's about asking your evil boss for a raise. The game is intended to be restarted multiple times in order to uncover the full story.
  • The Funny Place is a game made for the 2024 Global Game Jam. It is a sort of god game where you have to make people happy (or sad) by using the tools at your disposal. It was originally intended to be a sort of puzzle game where you have to balance tools that make people happy or sad to increase overall happiness as much as you can. Since we ran out of time, the game is actually more of a artsy tech-demo but the essential elements are there.
